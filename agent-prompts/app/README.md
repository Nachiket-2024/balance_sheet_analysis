# Your Agent Prompts

Nothing here yet. This is where your own project-specific agent prompts go
(e.g. "add a new domain end to end" for your own feature, a release
checklist, whatever you find yourself re-typing for an AI coding agent).
Upstream never adds anything under `agent-prompts/app/`, so nothing here
ever conflicts on a `scripts/mystic_auth/upstream-sync/sync-upstream.sh` run.

Template prompts (new-project setup, upstream sync) live in
`agent-prompts/mystic_auth/` instead: see [that folder's README](../mystic_auth/README.md).
