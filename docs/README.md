# Documentation
---

This directory follows the same ownership split as the application code.

1. **[`mystic_auth/`](mystic_auth/README.md):** upstream template documentation for architecture, authentication, authorization (PBAC), database, API routes, workers, security, testing, Docker, CI/CD, deployment, and [template usage](mystic_auth/template-usage/overview.md).
2. **[`app/`](app/README.md):** downstream project documentation. Keep product-specific notes here so future template syncs do not conflict with your application docs.

This mirrors the code split: `backend/mystic_auth/` plus `backend/app/`, and
`frontend/src/mystic_auth/` plus `frontend/src/app/`.

Start with [MysticAuth Documentation](mystic_auth/README.md). Flow diagrams live inside the relevant feature docs, so the explanation, code references, and diagram stay together.
