# Application screenshots

---

These dark-mode captures document the current application workflow at 1440×900
with the English interface and browser-local number and date formatting:

- `login.png`: sign-in screen
- `landing.png`: public product overview
- `companies.png`: authorized company list
- `company_detail.png`: company profile, provenance, and trend view
- `analysis.png`: deterministic balance-sheet metrics and warnings
- `financial_statements.png`: annual income and cash-flow tables
- `comparison.png`: selected-company summary metrics, quick filters, and results
- `management_review.png`: saved review, status, and comment entry
- `llm_chat.png`: company-scoped chat question and illustrative response

The examples use the disposable Microsoft-group seed data described in the root
README. Values are local illustrative fixtures, not live market data. The chat
image shows a mocked response; no paid provider was called to capture it.
